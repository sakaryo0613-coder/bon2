## P-000 dev-partner（モノを作り続ける仕組み）
- 目的: AIが開発者の立場で「要件→候補比較→仕様→実装・検証→登録→環境改善→次の提案」を回し、作るたびに開発環境も良くしていく
- 対象ユーザー: AI自身（Claude Code）と、方向性を選ぶユーザー
- 使う場面: ユーザーがモノづくりを頼んだとき、セッションを開始したとき、依頼なしで話しかけたとき
- 扱うデータ: 成果物の一覧、backlog、learnings、自作ツール
- 主な機能: 手順を定めたスキル（SKILL.md）、backlog 上位3件の自動提示（SessionStart フック）、`dp.py`（上位N件・lint・ID採番）、`shot.cjs`（スクショ自動チェック）、`build_compare.py`（候補の比較ページ生成）
- 保存場所: `bon2/.dev-partner/`。インストールは `.dev-partner/install.sh`。フックは `bon2/.claude/settings.json`
- 合格基準の要約: `dp.py lint` が OK、フックを模擬入力で実行すると上位3件が出る、`~/.claude` 側から全ファイルを参照できる
- 作成: 2026-11-19

## P-002 clipper（YouTube切り抜きツール）
- 目的: 長尺動画から Shorts / TikTok / Reels 向けのクリップを、少ない手作業で毎週作り続ける
- 対象ユーザー: ユーザー本人とスタッフ（非エンジニア・Windows）。好評なら販売もありうる。自分のチャンネル、または切り抜きの許諾を得た動画を扱う
- 使う場面: 長尺動画（配信アーカイブ・トーク）を公開した後の切り抜き作業（自分のPCで実行）
- 扱うデータ: 動画ファイル／URL（Twitch のアーカイブはチャットも）、字幕・文字起こし（文単位）、候補（文IDの範囲・点数・タイトル）、採否、書き出した縦型動画
- 主な機能:
  - 文字起こし（faster-whisper、または既存の字幕）
  - Claude（claude-opus-5-5）による候補の採点。使えないときはルール採点
  - レビュー画面（キー操作で採否、文単位の伸縮、タイトル編集、区間の再生）
  - 縦型 1080×1920 で書き出し（タイトル帯・字幕・出典・−14 LUFS）、説明文の下書き CSV
  - （B-008）Windows アプリ: インストーラー（clipper-setup.exe・管理者権限なし）、ホーム画面（動画を選ぶ → 候補を作る → 進み具合 → レビューへ自動で移る・最近の作業・設定）、初回ガイド（4ステップ）、書き出したフォルダを開く、窓を閉じると自動終了、二重起動しない、`--selftest`
  - （B-008）同梱物: ffmpeg（GPL ビルド）、日本語フォント（BIZ UDPゴシック・OFL）
  - （B-012）Twitch のアーカイブの URL を貼るだけで取り込む（動画 720p・チャット）。チャットの盛り上がり（平常の何倍か・3〜12秒の遅れ・山をどれだけ含むか）を採点に使い、理由に「チャット ×N」を出す。同梱の yt-dlp
  - （B-013）アプリ内の更新: ホームに今の版を表示。新しい版があると帯で知らせ、「更新する」でダウンロード → 照合（大きさ・sha256）→ 静かに上書き → 自動で開き直す。ブラウザを通さないので「危険」の警告が出ない
- 保存場所: `~/.claude/dev-partner/works/youtube-clipper/`（実体は `bon2/.dev-partner/data/works/youtube-clipper/`）。コードは `app/`、レイアウト調整は `tune/tune.html`
- 合格基準の要約:
  - B-001: AC1〜AC10 を自動テストで確認
  - B-008: AC1〜AC10 をローカル33件と Windows CI（GitHub Actions）で確認。英語音声の文字起こしと、インストール・アンインストールを含む
  - B-012: AC1〜AC10 をローカル71件・本物の Twitch・Windows CI で確認（作ったアプリで Twitch から情報・チャット・動画を取得）
  - B-013: AC1〜AC6 をローカル43件と Windows CI で確認。古い版（0.3.0）からアプリ内の更新で新しい版に上書きし、自動で起動し直すことまで確認
  - 未検証で B-004 に回したもの: 日本語の文字起こしの精度、yt-dlp、Claude の実際の採点、実機の見た目（実機での起動・インストールは 2026-11-19 にユーザーが確認済み）
- 配布物: GitHub Releases の最新版 https://github.com/sakaryo0613-coder/bon2/releases/latest/download/clipper-setup.exe（約170MB、ログイン不要）。main に反映するたびに CI が `clipper-v0.3.<実行番号>` を公開する。入れているアプリは「更新する」で更新できる
- 作成: 2026-11-19（B-001・案D 第1段階）。2026-11-19 B-008 で Windows アプリ化。2026-11-19 B-013 でアプリ内の更新に対応。2026-11-19 B-012 で Twitch の URL 取り込みとチャットの採点に対応
