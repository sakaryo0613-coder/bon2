# ナレッジ: 日本語の文字起こし・字幕・改行

日本語のテキストや字幕を扱う案件の着手前（手順0）に読む。B-001 で実際につまずいた点が元になっている。

## 文の区切り
| ルール | 理由・例 | 実装例 |
|---|---|---|
| 「。！？!?」で区切る。**ただし閉じ括弧の内側の！？は文末ではない** | 「先生！」って呼ばれて。→ 1文 | `clipper/transcript.py` `_pieces()` |
| 句点がなくても **0.6秒以上の無音**で区切る | 話し言葉の自動字幕は句点が抜ける。文と文の間の無音は一般に0.5〜1秒 | 同 `to_sentences()` |
| **1.0秒未満**の断片は前の文に結合する | 「はい」「で、」を独立した文にしない | 同上 |
| `[笑]` `[拍手]` `[音楽]` は YouTube の自動字幕の効果音表記 | 笑いは採点の手がかりになる。字幕に焼き込むときは `（笑）` に変換し、他は消す | `render.clean_text()` |
| YouTube 自動字幕（VTT）は前の行を繰り返すロールアップ形式 | 同じ行を二重に数えない。0.05秒未満のキューは表示切り替え用 | `transcript.parse_vtt()` |

## 話題の区切り（切り抜き区間の境目）
- 話題の切り替わりの手がかり：**0.8秒以上の間**、または転換のフレーズ（「話は変わ」「次は」「最後に」「ここで」「ところで」「〜の話をします」）
- 2つの話題の見どころを足し合わせた区間を高く評価しないこと。区間内に話題の切れ目があれば減点する（B-001 で実際に起きた）

## 話速（サンプルデータを作るとき）
- 雑談・トークは、間を含めて **漢字かな混じりで5〜6字/秒**。7字/秒以上で作ると全体が短くなりすぎ、尺の閾値のテストにならない（B-001 で起きた）
- ニュース原稿の読み上げは約6〜7字/秒

## 改行（字幕・タイトル）
1行の字数 = (幅 − 左右の余白) ÷ 文字サイズ。1080px幅・左右60pxなら、72pxで13字、64pxで15字。

| 優先度 | 規則 | 悪い例 → 良い例 |
|---|---|---|
| 必須 | 行頭禁則：、。」』）ー っゃゅょ… を行頭に置かない | — |
| 必須 | 促音「っ」の直後で改行しない | 今年買ってよかっ／た → 今年買ってよかったもの／ランキング |
| 高 | 読点「、」の後で改行する | — |
| 高 | 助詞・活用語尾（は が を に で と の も へ や た て る い く し だ ら ば ど ね よ）の直後で、漢字・カタカナ・数字が始まる位置は文節の切れ目 | 置い／たら1週間 → 置いたら／1週間 |
| 中 | 漢字→ひらがな（送りがな）の位置では改行しない | 続／けた |
| 中 | 熟語・カタカナ語の途中で改行しない | 結／果、ラン／キング |
| 中 | かぎ括弧の途中で改行しない | 「どうやって／続けてる？」 |
| 低 | 2行の長さはなるべく揃える | — |
| 例外 | 「一か月」の「か」は助詞ではない。BUNSETSU_END に「か」を入れない | 一か／月 |

- 改行の規則を変えたら、**例文と期待する改行の表（`tests/test_wrap.py`）を全件流す**。目で1件ずつ直すと後退に気づけない（B-001 では4往復かかった）
- 上限ちょうどの長いタイトルは改行位置の自由がなくなる。上限内の最後の読点で切る（`fit_title()`）
