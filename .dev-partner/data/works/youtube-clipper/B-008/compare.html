切り抜きツールを「コマンド入力なし」で使う方法 — 4案の比較

B-008 / 手順2。各案の画面は「使う人が最初に見る画面」のイメージです（画面をクリックすると原寸）。どの案でも、レビュー画面には初回の使い方ガイド（再生 → 採否 → 伸縮 → 書き出し）を付けます。下のバーで選んで「選択をコピー」→ チャットに貼り付けてください。

前提・仮説

  • 目的: ターミナルを使ったことがない人でも、動画を選ぶ → 候補 → 採否 → 縦型動画までたどり着ける
  • 成功指標: コマンド入力0回（初回の準備も含む）、2回目からは3操作以内で候補づくりを開始できる、初回の準備は15分以内で放置してよい
  • 現状: 起動に「python -m clipper run …」の入力が必要（L-008）

比較軸: ①処理する場所（手元のPC ↔ クラウド）× ②始め方（自分で起動 ↔ Claude に頼む）

推奨：案B「Claude に頼むだけ型」

推奨は B です。非エンジニアがつまずくのは、ほとんどが初回の準備です（Python や ffmpeg のインストール、Mac の「開発元を確認できない」警告など）。Bでは Claude がその場で状況を見て準備し、エラーが出ても直してくれます。Aのスクリプトは、想定外の環境で止まるとユーザーには直せません。また、すでに Claude を日常的に使っているので、新しく覚える操作がありません。実装は最も小さく（2〜3時間）、Aは後から追加できます。スタッフにも渡すならC、PCに何も入れたくないならDが向きます。

A
ダブルクリック起動＋自動セットアップ型
狙い
フォルダの「はじめる」をダブルクリック → 初回だけ必要なものを自動でインストール → ブラウザの画面で動画をドラッグして「候補を作る」
向くケース
Claude を使わずに単体で動かしたい。動画を手元から出したくない
弱点
初回の自動インストールが環境によって止まることがあり（Mac の警告、ffmpeg の入手など）、止まったときにユーザーは直せない。Mac と Windows で起動ファイルを別々に用意する必要がある
規模
半日〜1日（工数2）
処理: 手元のPC始め方: ダブルクリック費用: 無料
B
Claude に頼むだけ型
推奨
狙い
「この動画を切り抜いて」と話しかけるだけ。準備・実行・レビュー画面を開くところまで Claude がやり、書き出し後の確認や「字幕を大きく」などの調整も会話で済む
向くケース
普段から Claude（Claude Code / Cowork）を使っている人。初回の準備でつまずきたくない人
弱点
PCで Claude Code か Cowork を使えることが前提。Claude なしでは他の人に渡しにくい
規模
2〜3時間（工数1）
処理: 手元のPC始め方: Claude に頼む費用: 無料（Claude の利用枠内）
C
デスクトップアプリ型
狙い
ffmpeg などを同梱した普通のアプリ（.app / .exe）にする。インストールはドラッグするだけ
向くケース
スタッフや知人にも配りたい。Claude を使わない人にも渡したい
弱点
作るのが重い（OSごとにビルドし、警告を出さないための署名も必要）。サイズは約500MB。更新のたびに配り直しが必要
規模
2〜3日＋署名の準備（工数4）
処理: 手元のPC始め方: アプリを開く費用: Apple の開発者登録 年1.2万円程度
D
クラウド版（ブラウザだけ）
狙い
PCに何も入れない。専用ページに動画をアップロードするとクラウドで処理され、採否はスマホからもできる
向くケース
PCに何もインストールしたくない。外出先やスマホで採否を決めたい。複数人で使う
弱点
サーバー代が月2,000〜5,000円かかる。60分の動画（数GB）のアップロードに時間がかかる。動画を外部に置くことになり、運用（障害対応・削除）も必要
規模
3〜5日（工数5）
処理: クラウド始め方: ブラウザ費用: 月額あり
