# B-008 clipper の Windows アプリ化 — 仕様（02-spec）

決定（2026-11-19）: 「おまかせ」→ 案C「Windows アプリ型」。最初の画面のデザイン比較は L-004 により省略し、案C のファーストビューを基準にする。
目的: スタッフ（非エンジニア・Windows）が、コマンド入力なしで「動画を選ぶ → 候補 → 採否 → 書き出し」まで使えること。
この案件は、dev-partner の手順のテストも兼ねる。

## 構成
```
clipper-setup.exe（Inno Setup）── インストール → スタートメニュー・デスクトップに「clipper」
clipper.exe（PyInstaller・コンソールなし）
  ├ 127.0.0.1 の空いているポートでアプリのサーバーを起動（ホーム画面・レビュー画面・API）
  ├ Microsoft Edge のアプリモード（--app）でウィンドウを開く。Edge がなければ既定のブラウザ
  ├ 同梱物: ffmpeg/ffprobe（BtbN の GPL ビルド）、日本語フォント（BIZ UDPゴシック Bold・OFL）、サンプル
  └ 初回だけ、文字起こしモデル（faster-whisper small, 約500MB）を %LOCALAPPDATA%\clipper\models にダウンロード
作業フォルダ: %USERPROFILE%\Documents\clipper\<動画名>.clipper\   出力: その中の out\
設定: %APPDATA%\clipper\config.json（Claude APIキー〈任意〉、出典表記の既定値）
```

## 数値と根拠
| 項目 | 値 | 根拠 |
|---|---|---|
| ウィンドウ | Edge のアプリモードで**最大化**して開く | ノートPCで多い 1920×1080・表示倍率150% だと、実質の表示領域は 1280×720。窓を小さく開くと操作ボタンが画面外に出る（L-005） |
| 想定する最小の表示領域 | **1280×680**（ボタンがファーストビューに入ることを確認する）、加えて 1024×680 | 1280×720 からタイトルバーとタスクバーの分を引いた値 |
| 終了の判定 | 画面から**10秒ごと**に生存通知。**60秒**届かず、処理中でもなければ終了 | ウィンドウを閉じれば1分以内に終わる。再読み込み程度では終わらない |
| 二重起動 | 2回目の起動では新しいサーバーを立てず、既存のサーバーで窓を開く | アイコンを2回押しても壊れない |
| 操作回数 | 起動 →「動画を選ぶ」→「候補を作る」の**3操作** | 成功指標（00-brief） |
| 動画の選び方 | 「動画を選ぶ」ボタンで Windows 標準のファイル選択画面を出す（パスだけ受け取り、コピーしない）。ドラッグ＆ドロップの場合は作業フォルダにコピー | 数GBの動画をコピーしない。ドロップはブラウザの制約でパスが取れないため、コピーになる |
| 進み具合 | 段階（準備 → モデル取得〈初回のみ〉→ 文字起こし〈%表示〉→ 候補づくり）を表示。文字起こしは処理済みの秒数 ÷ 全体 | 20分かかる処理で「止まった」と思わせない |
| 初回ガイド | レビュー画面の初回に4ステップ（再生 → 採否 → 伸縮 → 書き出し）を重ねて表示する。「？」で再表示。表示済みかどうかはブラウザ側に保存 | 説明書を読まない前提 |
| フォント | 同梱の **BIZ UDPゴシック Bold** を `fontsdir` で指定する | Windows Server を含むどの環境でも同じ見た目になる。OFL なので販売物にも同梱できる |
| ffmpeg | BtbN の win64 GPL ビルド（libass・libx264 を含む） | 字幕の焼き込みと H.264 に必要。※販売時は GPL への対応（ソース提供など）が必要（別案件） |
| サイズ | インストーラー 400MB 以下が目安 | 社内でファイル共有できる大きさ |

## 合格基準
| # | 基準 | 判定方法 | 場所 |
|---|---|---|---|
| AC1 | コマンド入力ゼロで、起動から候補づくりの開始まで3操作 | Playwright で、ホーム画面の「動画を選ぶ」（選択画面はテスト用に差し替え）→「候補を作る」の2クリックでジョブが始まることを確認 | ローカル・Windows |
| AC2 | 進み具合が段階ごとに表示され、終わるとレビュー画面に進む | 同上（段階の表示が変わり、最後にレビュー画面へ移る） | ローカル |
| AC3 | 初回ガイドが出て、閉じると次回は出ない。「？」で再表示できる | Playwright | ローカル |
| AC4 | ホーム（「動画を選ぶ」「候補を作る」）とレビュー（「採用」「却下」「書き出す」）の主要ボタンが、1280×680 と 1024×680 でファーストビューに入る | `shot.cjs --must-see` | ローカル |
| AC5 | 書き出し後に「フォルダを開く」がある。最近の作業から再開できる | Playwright と API のテスト | ローカル |
| AC6 | 窓を閉じると、処理中でなければ終了する。処理中は終了しない。二重起動しない | 判定時間を短くした単体テスト | ローカル |
| AC7 | 既存のテスト（25件）が Windows でも通る | GitHub Actions（windows-latest）で pytest | Windows |
| AC8 | 作ったアプリ（clipper.exe）が Windows で動く：同梱の ffmpeg とフォントで、候補づくり → 書き出し → 形式の確認まで通る | `clipper.exe --selftest`（Actions） | Windows |
| AC9 | インストーラーで入れたアプリが動き、ショートカットができ、アンインストールできる | サイレントインストール → `--selftest` → アンインストール（Actions） | Windows |
| AC10 | 作ったアプリの中で文字起こし（faster-whisper）が動く | Windows の音声合成で作った英語の音声を、アプリの文字起こしにかけ、時刻つきの結果が返ることを確認（Actions） | Windows |
| AC11 | 実際の PC での見た目（Edge の窓）、SmartScreen の警告からの起動手順、日本語の文字起こしの精度 | **ここでは検証できない**。B-004 でユーザーの PC で確認する | ユーザーPC |
