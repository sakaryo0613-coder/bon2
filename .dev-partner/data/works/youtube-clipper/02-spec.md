# B-001 YouTube切り抜きツール — 仕様（02-spec）案D・第1段階

決定（2026-11-19）: 「おまかせ」→ 案D「候補推薦＋人が採否を決める型」。Q1〜Q3 は仮説のまま進める。
- 自動化の範囲: AIが候補を出し、人が選ぶ
- 出力: 縦型ショート
- 素材: トーク中心

第1段階で作るもの：文字起こし → 候補の採点 → レビュー画面 → 縦型・字幕つきで書き出し。
第2段階（B-001 の続き）で入れるもの：チャット・音量・「最も再生された部分」の信号、顔を追う縦型切り出し。

## 処理の流れ
```
python -m clipper run <動画ファイル|URL> [--subs 字幕.srt|.vtt]
  1) prepare     動画を作業フォルダ <名前>.clipper/ にコピー。URLなら yt-dlp で取得
  2) transcribe  --subs があればそれを使う。なければ faster-whisper で文字起こし
  3) sentences   文の単位に分ける → sentences.json
  4) candidates  候補を作って採点 → candidates.json（APIキーがあれば Claude、なければルールで採点）
  5) review      http://127.0.0.1:8765 でレビュー画面を開く（採否・文単位の伸縮・タイトル編集）
  6) render      採用した候補を 1080×1920 で書き出す → out/
```

## 数値と根拠
| 項目 | 値 | 根拠 |
|---|---|---|
| クリップの長さ | **20〜60秒**（狙いは30〜50秒） | 60秒以内なら YouTube Shorts・TikTok・Reels のどれにもそのまま出せる。20秒未満だと文脈が伝わらない |
| 開始・終了の位置 | **必ず文の境目** | 成功指標「文の途中で始まったり終わったりしない」。候補を「文IDの範囲」で表すので、構造上ずれない |
| 前後の余白 | 開始 **−0.3秒**、終了 **+0.5秒** | 文字起こしのタイムスタンプは0.2〜0.5秒ずれる。最初の子音の欠けと語尾の切れを防ぐ |
| 文の区切り | 「。！？!?」、または **0.6秒以上の無音** | 話し言葉の文字起こしは句点が抜けやすい。文と文の間の無音は一般に0.5〜1秒 |
| 短すぎる断片 | **1.0秒未満**は前の文に結合 | 「はい」「で、」のような断片を独立した文にしない |
| 候補数 N | **動画の分数 ÷ 5**（最小5・最大20）。60分なら12 | 必要な5本 ÷ 採用率50% = 10本に予備2本。12候補 × 60秒以内 = 12分以内で、人の作業15分に収まる |
| 候補の重なり | **重なり0秒** | 同じ場面の重複は確認時間の無駄 |
| レビューでの伸縮 | **文単位**（前の文を足す／先頭の文を削る／末尾の文を削る／次の文を足す） | 秒単位で伸縮すると文の境目の保証が崩れる |
| ショートカット | A=採用、X=却下、J/K=次・前、Space=再生 | 1候補15〜60秒で判断するため、マウス操作を減らす |
| 出力解像度・fps | **1080×1920・30fps** | Shorts の推奨解像度。60fps にしてもトーク動画では差が小さく、容量が倍になる |
| 映像コーデック | H.264（libx264, CRF 20, preset medium） | どのSNSにもそのまま上げられる。CRF 20 はアップロード後の再圧縮に耐える画質 |
| 音声 | AAC 160kbps 48kHz、**ラウドネス −14 LUFS**（True Peak −1.5dB） | YouTube や TikTok の再生側ラウドネス正規化の基準が約 −14 LUFS |
| レイアウト（既定） | **帯レイアウト**: 上がタイトル帯、中央が16:9の動画（1080×608, y=656）、下が字幕 | 横動画を切らずに使え、顔の位置を追う処理が不要（第2段階で `--layout crop` を追加） |
| 安全領域 | 文字は **y=240〜1520、x=60〜1020** の内側 | Shorts の上部（検索など）と下部（タイトル・いいね等）のUIに隠れない範囲 |
| タイトル | 最大 **2行 × 13字**、72px、太字、白 | (1080 − 左右60px) ÷ 72px ≒ 13字。3行以上は流し見で読まれない |
| 字幕 | 64px、白文字＋黒縁6px、最大 **2行 × 15字**、動画の下（y≈1290〜） | (1080 − 120) ÷ 64 ≒ 15字。動画に被せないので顔を隠さない |
| 出典表記 | 動画の右下、32px、半透明 | 切り抜きガイドラインの多くが出典表記を求める（H1）。`--credit` で文言を指定 |
| フォント | 次の順で最初に見つかったもの：Hiragino Sans → Yu Gothic UI → Meiryo → Noto Sans CJK JP → IPAGothic。`--font` で上書き | Mac・Windows・Linux の標準で日本語が出るものの順 |
| LLM採点 | `claude-opus-5-5`、effort high、構造化出力、拒否時は自動フォールバック | 面白さ・完結性の判断は難しいので high にする。費用は60分の動画で数十円程度（入力約2万トークン） |
| 文字起こし | faster-whisper `small`（CPU, int8）。`--model medium` で精度を上げられる | small は CPUで動画の長さの0.3〜0.5倍の時間で済み、日本語の精度も実用範囲 |

## ルール採点（APIキーがないとき・オフライン時）
基本点40に次を足し引きし、0〜100に収める：

- 加点
  - 笑い（「笑」「www」「ははは」等）: +12（最大+24）
  - 感情・強調（「マジで」「本当に」「めちゃくちゃ」「正直」等）: +5（最大+20）
  - 結論・順位（「第1位」「結論」「一番」「結果」等）: +10（最大+20）
  - 質問と回答の組（区間内で質問の文の後に回答がある）: +10
  - 最後が文末表現で終わる: +10
  - 1秒あたり4〜9字の発話密度: +5
  - 長さ30〜50秒: +5
- 減点
  - 先頭が接続詞（「で、」「だから」「それで」）: −10
  - あいさつ・告知（「こんにちは」「チャンネル登録」「告知」等）: −15

**この採点は予備の扱い。** 本命はLLM採点で、実際の動画での品質は LLM採点 ＋ 人の採否で担保する。
